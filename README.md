A terrifyingly simple and absurd new inserter.
Picks up items from the same spot they came from.
Useful for asteroid crushing, nutrients production, catalyst recipes and all this sort of stuff!

The ancient gods of Factorio balanced its immense power by limiting his speed and hand size though...
